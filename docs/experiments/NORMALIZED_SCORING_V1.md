# 百分制指标与固定权重方案 v1

2026-11-02 用户授权把既有两类指标同时展示原始口径与百分制分数，并给加权总分。此增量只改实验评估器，不改产品协议、提示、State、Window 或原实验。历史结果写独立新目录，原报告、证据、账本和哈希不覆盖。

## 分数的含义

版本为 `normalized-20261102-v1`。每行由同一 registry 生成 ID、含义、原始公式、单位、转换公式、方向、评分资格、权重依据、阈值依据、来源及缺证据原因；JSON、CSV、Markdown 使用同一字段。诊断计数不是独立质量目标，没有预登记目标则分数为空、权重0，而非任意认定越多越好。

- 成功率、合格二元断言和覆盖率：100p；错误或违约率：100(1-p)。合法概率必须在[0,1]，异常值为invalid，不裁剪掩盖。
- F/D新增密度：x在[0.05,0.10]得100，x低于下界为100x/0.05，高于上界为100×0.10/x。沿用既有诊断策略闭区间，非普适最优值。累计新增F/D包含modify_fact新建的Fact，不含Goal/归档/幂等重放。此分只衡量节奏策略，不代表语义价值。
- 内部批次间隔CV：100/(1+CV)。等内部间隔得100，离散增大时连续递减；无额外经验阈值。至少三个成功写批次、两个内部间隔且均值正；否则不足样本。首段p1、尾段R-pk及最大间隔仍单列，不能由CV代替。
- 缓存主分：100×hit/input；辅助100×hit/(input+output)。利用度不代表质量，两profile权重0。
- 相对费用指数：100×C_native/(C_native+C_plugin)=100/(1+r)，同费50、半价66.67、双价33.33。它不是节省率或质量收益，权重0。两侧均0为N/A；原生0且插件正费用时指数0、原比值仍N/A。任务、模型、价格、USD及费用证据必须匹配。跨题先求费用和再映射，不平均指数。

## 缺失、区间与可比性

每叶子保存score、status、coverage和[lower,upper]。例如s成功/f失败/u未知，N=s+f+u：观测分100s/(s+f)，覆盖(s+f)/N，区间[100s/N,100(s+u)/N]。N=0无机会，不能填100；分母或来源缺失为unknown。invalid不参与已知均分，必须保留错误原因。

固定权重w下，总覆盖C=Σw×coverage/Σw；已知均分=Σw×coverage×observed_score/Σw×coverage；全profile区间由各叶子的上下界加权。只有C=1且全部适用叶子证据完整才给点总分，否则point=null，显著标暂定并展示已知均分、覆盖和区间。区间下限是已证实贡献，不是认定unknown为0。自然未触发检索/引用等保留覆盖缺口，权重不转移。原生无State为插件profile结构性N/A。

同题比较还展示相同叶子、双方共同已知证据权重的配对均分及共同覆盖；不拿不同已知子集的暂定均分直接判胜。跨三题按任务各1/3宏平均，不按测试数量或调用量加权。硬契约失败单列，不由其他高分抵消。

## 实现与验收边界

新增实验评分模块由既有report/campaign自动调用；历史用同一CLI的score-report写新目录。14个事后离线案例只验证oracle，不能倒填为旧模型行为。旧wasm准备边界缺证据仍unknown；旧保护约束在驱逐前已破坏，跨窗0只作原代理展示，不能称遗忘或采用率0。

验收覆盖映射边界、null/NaN/负值/零分母、部分工具结果、固定权重不重分、两profile、同题共同覆盖、任务宏平均、原始文件不变及未来report/campaign接线。不发起模型请求。
