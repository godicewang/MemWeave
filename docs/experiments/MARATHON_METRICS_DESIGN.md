## 请求准入与观测

原 LiveObserver 的事后用量不足以保证硬限额。两组共同使用实验专用 Node preload，只拦截 Node 全局 fetch 的 DeepSeek chat/completions 请求，不改请求内容、模型、工具或回执字节。每个 HTTP 尝试先在共享的小型额度文件中加锁预留：最多 1,000,000 输入 token、请求输出上限（不超过 384,000），按输入 0.30/输出 1.20 USD/M 峰值价计算。未确认 usage 保留全部预留；确认 usage 才按同一峰值价结算退款。预留、已结算及未知费用之和不得超过 29 美元，另留 1 美元余量；截止后拒绝新请求并中止在途请求。所有重试、原生压缩均经过同一传输边界，不依赖扩展 hook 是否覆盖压缩。禁止新增付费工具端点、其他模型或绕开守卫的入口。

共享挂载仅含 quota 账本，不含题目、回答、金标、另一组工件或凭据。守卫保存请求 hash、消息角色/大小、Rule/State/Window 摘要、实际 HTTP 状态、usage 和请求编号；不另存完整聊天。原始文本仍仅由 Pi Session 保存。定向案例在提交、写文件及依赖动作边界保存必要的受保护文件 hash、Cargo 依赖和 State 有效投影，位于评估日志而非模型上下文。
