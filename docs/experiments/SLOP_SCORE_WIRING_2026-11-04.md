# Slop原始阶段结果的百分制接线

本轮Slop尚无正式Actor派发，先冻结下列报表解释及测试。SCB-01／03已有当前功能与历史回归检查点；SCB-02已有五项外键业务断言、两个时序State检查点及Task连续性。它们不等于任意自由文本记忆、通用纠错或Task恢复能力；补充断言不重复加权。

`S3.partial_pass_rate`在Slop没有唯一的平坦测试数分母，使用每个固定checkpoint的**原始报告 passed/total**的等权均值，再乘100。原始计数包含已报告的条件跳过测试，不能偷换成派生适用集分母。每个原始checkpoint的分子分母在证据中保留。已完整证明缺少原生必交文件的阶段贡献为0，明确称交付门禁失败，实际执行测试数仍为0／未执行，不伪造“全部测试实际失败”。缺报告或分母损坏仍missing／invalid，不能当该门禁失败。

SCB-02的`S.common.process_validation`取固定五阶段**原始严格**checkpoint通过数／5；各checkpoint内部必须全部原始报告测试通过，跨checkpoint按事前定义等权聚合。此前reference在阶段3–5有条件skip，故该控制是2/5=40分，整体原始严格0；独立派生适用测试通道仍100。该值不是模型成绩，也不修改原始／派生结果。`S.common.protected_constraints`仍只取第3阶段固定五项FK／回滚断言AND，与阶段协议明确分列。

归一化显式证据应优先于通用的passed/total默认字段；否则一个已给出的有效案例级宏平均会被通用缺字段状态覆盖。修复只影响未来或新输出的离线评分，不覆写既有报告、权重、Actor提示、资源、原始工件或本轮已完成MAB／TB结果。SCB-01／03仍用独立的旧功能回归均分及当前功能均分，不被本接线换掉。

Slop原生verifier在Harbor Actor结束后由宿主运行，不能从被禁用的Harbor verifier阶段伪造耗时。新执行以monotonic时钟采集每臂实际宿主验收墙钟（含交接检查和原eval-snapshot），接入Q6.phase.verifier，并标明范围；即使因必交文件缺失而未执行pytest，交接门禁实际耗时仍可测。旧报告没有时钟时保持unknown，不用文件mtime推算或补0。

1103项实验全量回归及Ruff通过；专项报告集成控制验证原始严格0、检查点部分宏平均、SCB-02阶段40与派生100分列。保留的真实Pi假provider旧轨迹离线复算也得到原始0／部分99.45318937012871／FK业务100／阶段40；该旧控制没有供应商cache字段或宿主验收时钟，8项诊断仍缺证据，采集验收明确false。不能把这些软件控制当模型成绩，正式准入前需要当前采集版本的新控制。
