# WDM 选题输出工件检查点

仅增加现有实验评估侧的LONG-02组件，不修改产品、原题正文或原验证器。依据锁定TB4 `wdm-design/instruction.md`及`tests/test_state.py`，对最终`meta.json`与`design.npy`作独立的程序检查：文件存在、几何字段及数值范围、数组float64／二维形状／有限范围、每个像素严格小于0.05或大于0.95。必需子断言AND通过才给该检查点100，否则0；子断言不重复计权。它不替代最小特征DRC、两次FDTD、带宽／透射／泄漏的原始验收，也不证明State采用。

评估观测器只对契约显式列出的两个工件捕获既有边界内容，单文件最多1MiB，拒绝路径越界和符号链接。内容放在已有evaluator-only CAS，不进入模型上下文；按真实字节hash关联，未增加聊天副本。最终边界必须存在并与独立执行日志完整性一致。结束时明确无工件是已知失败；边界、CAS或读权限丢失是缺证据，需修复，不能充当设计NA。允许格式但不在解析器受支持的NPY版本／描述表达式范围时缺证据；已知损坏／不合题面格式为失败。不得执行pickle或数组内代码。

源任务生成入口锁定批准设计的LONG-02 pin、原题hash及原验证器hash；新增契约保存在evaluator-only目录。旧报告不覆写，免费真实CLI控制及原件离线检查分开标注，不能当作正式模型分数。每个检查点有正例、逐类负例及缺证据测试；只有输出条件通过不代表题目解出。

已通过现有`fixed35 wdm-contract`入口冻结13个必需断言，`fixed35 report`自动生成原始值、百分制、支持计数与新ID的派生明细。该明细权重0，主共同检查点只计权一次。NPY v1/v2/v3按受限字面头解析，不执行pickle；遵守原`np.load`读取首个数组及`json.load`重复键最后值语义，不引入隐藏格式惩罚。

`wdm-artifact-cli-v2`的5个真实Pi CLI／本地假provider控制已完成：两臂正例均100，原生错误端口几何、插件灰度数组、原生缺数组均0；12个模拟HTTP请求、工具错误0、边界采集完整，容器和模拟额度服务已停止。没有读真实密钥，没有DeepSeek费用。几何／数组／缺证据是独立断言，单测覆盖截断CAS、非有限值、严格二值边界及路径／大小拒绝。

v1控制误用未经缓存改写的源任务，安装前缺镜像映射而失败；其证据保留，零模型请求。v2的五个控制本身全通过，首次报表因派生明细缺`weights`失败；只修报表映射，原件在新`reports-complete-v12`离线重算，两臂各170行及一行派生明细，不再请求provider。整题采集验收仍false，不将本组件当正式准入。两份既有官方参考输出也单独通过格式检查100，仍与原始光学reward分列。
