# MAB三次切窗的证据边界

只修改现有离线oracle。先前以完整ingest文本子串消失判断原始证据不可见，可能漏掉仍在工具结果或引用中的关键原文片段。对已有source-bound压力契约，新版同时检查金标支持片段在所有非State请求消息中不可见，并要求相同request_id的独立原生事件Window oracle通过。State中的已保存记录参与保留判定，不混入原文可见性。

三个预登记检查点分别列独立边界ID、原文不可见、当前事实保持、实际交付版本、独立Window投影五个程序断言；每点AND，C4要求三点都通过。缺少原始消息／Window证据保持missing，不当完美切窗；重复或已知错误边界为失败。少于三次真实切窗是未触发的计划槽位，不能改设计NA或补无意义交互。没有配置独立Window的早期控制明确属于旧判别，不声称新版全量证据。

另有一项完整边界序列断言，核对原始Pi执行日志与采集回调，防止漏掉中间切窗却挑出三个后来正例。整段采集不完整时不能声称计划槽位只是没触发；已知错误仍0且缺证据标记不消失。共16项断言，其中15项归属于三个具体检查点。

该项证明有限typed gold在三个真实请求边界的保持，不证明模型阅读、因果收益或所有自由文本语义。现有报告／raw不覆盖，新评分器版本另存；改变只是离线判定，未反馈给actor，不需要重跑模型。仍需实际长任务／模型运行才能产生正式成绩。

本切片还把已实现的选题gold接入现有百分制报告：MAB-05的当前事实卡及MAB-06／07／08各自不同的书籍事件卡，对应设计明确分配的C1必记证据保全点；分别核对实体／关系／限定、无已知相反有效记录、写入先于实际回答文件动作及该动作使用正确值。其余题不自动补C1分。四种book关系仍来自各自锁定source，不是换标签复用同一个金标；这个有限格式判定不能泛化为开放文本的重要性判断。子断言不另加权，未改变既有family权重。

v15进一步修复矛盾卡片的scope：只有已知错误字段与其余目标事件字段／条件同时匹配，才认定该目标事件的矛盾。不能仅凭同一人物就排斥不同动作／场景下的有效事实。四个选题分别覆盖同事件反证、同人物其他事件与其他人物的正负控制；仍只判断预登记的有限不兼容集合。

新增`pressure-books-threecases-v1`实际CLI软件控制覆盖MAB-06／07／08原生／插件六臂；保留已冻结的自然文本和N=20／B=4，不添加填充。每臂34个源阶段完整，原生各35、插件各37模拟请求，共216。三个插件臂的C1、C4与同请求独立Window全通过，实际State版本交付率1；每臂各一次state_append成功、无错误，原生对应操作设计不适用。所有216个请求的真实API资格计数都是0，不能累积为千次长程验收。容器与模拟服务停止，真实账本hash不变。

28份更早控制已在新目录离线复算：四个事实压力正例C4为100，保留过时事实为0，书籍中途丢失后补记为0；无三次机会的早期普通book控制仍缺证据。八题各经现有report生成两臂×170行，保留完整案例契约尚未解决、旧采集阶段声明缺口以及正式验收false。不能把控制100当DeepSeek能力分。v15最终全量663项实验测试、276项仓库检查、类型／资源／Ruff／diff检查通过；没有新增付费模型请求。
