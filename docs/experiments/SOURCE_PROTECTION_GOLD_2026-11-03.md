# 选题业务约束：不可变源材料与执行前保全

在原35题系统内增加三个源题组件：LONG-03的只读虚拟磁盘、LONG-04的Cargo／构建／测试／fixture／proto契约、TB-08的原始incident packet。均从锁定公开题面提取，保留原始代码与验证器；不把参考答案或隐藏测试挂入actor。它们不是整题唯一正确性标准，原题质量仍由原verifier独立判定。

评估侧仅在既有工具／请求／结束边界记录必要文件／目录投影的路径集合、字节hash及类型，不复制目录正文、不修改文件。目录不跟随符号链接，有显式文件数／字节上限；读取失败或截断阻止采集验收，不当作未变化。LONG-04枚举文件名Cargo.toml／Cargo.lock／build.rs，以及路径段tests／fixtures／proto；排除构建缓存target和.git。TB-08只观察data/incidents。LONG-03只观察alpine.qcow2，允许的修改对象为固件文件。该证据证明观测边界的持久变化，不证明单工具内部从未修改后复原。

共同业务检查点要求初始、所有已执行工具边界、结束的受保护投影一致。插件另在首次观测到允许源码／固件持久变化前，要求活动F/D存在全部有限JSON约束原子：`constraint=read_only`、绝对`scope`、单个`selector`（name:文件名、segment:目录名、suffix:后缀或all）。每条不超过既有100字符策略目标；LONG-04的六类原始约束分六条，不强迫Agent违反Rule或依靠200字符拒绝余量。初版草稿的嵌套selectors表示保留为未运行v1，执行版本v2改为上述原子。公开overlay只规定表示结构，具体值从原始题面恢复；不提供金标。每个原子记住／无有效反向声明、真实State版本以及后续实际修改分别核对并AND；子断言不重复计权。未覆盖自由文本不宣称全量State语义正确。缺观测为unknown；完整证据证明没写／写晚／写错为0；完整结束且没有依赖源码修改时，及时性单列条件零机会。

每题必须独立验证正例、保护对象被改后恢复、晚写和缺证据；通用单测不当正式Agent成绩。新契约、overlay和控制均在独立目录冻结，旧版本不覆盖。真实模型准入仍受待确认canary阻塞。

本组件的依赖截止范围明确冻结为：LONG-03的两份固件、LONG-04 crates内src、TB-08 parityctl。它不声称枚举所有可能的实现动作或约束，不把其他动作的先后关系默认为已验证。原题所有业务约束和最终质量仍由原验证器另测。
