# 49题 Pi / MemWeave 运行审计与机制分析

状态：最终49题审计，2026-10-29。49个题对、98个唯一主结果及首个有效官方评分齐全；证据索引检查无损坏。原生27／49（55.1%），插件25／49（51.0%）。本次没有证明插件改善整体任务成功率；三项明确的插件独过均有业务原因，但不能唯一归因于记忆机制。完整逐题表与费用／时间口径见[最终对照](LONG_HORIZON_49_FINAL_REPORT_2026-10-29.md)，全部失败与评分疑点索引见[badcase报告](LONG_HORIZON_49_BADCASE_REPORT_2026-10-29.md)。

## 判断边界

本批使用同一冻结生产候选、同一模型、同一官方任务和预算。每次解题从独立容器、配置、Session和记忆开始；SWE按官方V2协议在新沙箱重放原补丁评分。当前§22续跑保留正常单侧首0／首1；早期整对恢复的重复尝试与协议时点限制须单列，见下文MW-013N。中断、模型前失败、评分失败、后续原产物评分分别保留。具体记录见[实时表](LONG_HORIZON_49_LIVE_COMPARISON.md)与[连续观察](LONG_HORIZON_49_LIVE_OBSERVATIONS.md)。

主表每个槽位每变体保留一个主结果；存在基础设施恢复及早期整对重跑，额外尝试另列，不能当全程严格单次推理试验。这份配对工程样本包含不同工具、Rule、State和窗口策略的整体差异；单次胜负不能唯一归因于记忆模块。模型写入的Fact是被测产物，不是审计事实；只有原工具回执、源码、Session角色、官方原件和可复现诊断能支持结论。

- SWE35题原生25／35、插件24／35；TB14题原生2／14、插件1／14。插件超难档10／21、原生9／21，只是本次结构预评级样本的描述，不能盖过整体结果或视作难度越高记忆收益必然越大。
- 49题机制审计中仅T05／T07发生窗口移动，原生均没有压缩事件，插件没有调用memory_read。T12原生最大input+cacheRead约39.4万tokens、512次模型返回；插件约5.3万／67次，提前停止且未实施。多数结构上复杂的题没有实际触发窗口移出；这批结果主要覆盖完整插件的工具／State使用与工程决策，尚不足以建立长程遗忘被改善的结论。
- 全49题原生Agent46540.718秒／$4.652204412、插件22111.076秒／$3.362061600，插件低52.5%／27.7%。但双方官方通过的22题，原生6713.448秒／$0.522629772、插件7800.274秒／$0.794384352，插件反而高16.2%／52.0%。这22题仍含S35解析器限制；仅作费用解释另看其余21个同过任务，仍高17.3%／54.6%，主表49不变。SWE中插件费用本就较高（$1.373509对$0.944357）；总体降低主要在TB，包含提前结束和原生长搜索，不能称同质量加速。
- 较短Agent时间可能来自过早结束或较弱验证。T07插件没有修复坏块，原生则进行了大量训练但生成近似替代数据，两者整题均0；不能把较快失败当能力收益。按“双方都通过”的任务单列费用和时间，避免失败任务主导汇总比值。
- 49题插件主尝试中，记忆业务工具共224次错误回执：state_append 188、task_create 33、modify_fact 3；其中214次为长度拒绝、其余10次是JSON／参数验证。state_append共272调用，188错误约69.1%；task_create共82调用，33错误约40.2%，剩余49次成功恰对应49个任务。这是工具回执数，不是失败任务数。部分State还把待证结论写成已验证事实；这属于工具成本与认知质量证据。没有原件证明时，不将其归为State持久化损坏或窗口必然丢失。

## Good case 的实际范围

S28 Teleport，官方要求的TestColumn／TestMessage原生均失败、插件均通过，首分0／1。原生仅按RFC3339Nano解析，不能读取PostgreSQL常见的`2023-09-05 15:57:01.340426+00`，列读取及insert事件都在解析expires处失败；这是业务数据格式支持不足，不是评分报告格式错误。插件自建的`2023-09-26 10:00:00+00`与`+02`用例在隐藏评分前已真实失败（4166123b），随后增加多布局解析，原自测及最终pgbk build／vet／测试通过（db55a9ba）。原生也有自测并最终通过，但没有覆盖这类时间文本，不将它说成从未验证。

插件61次返回、734.972秒／0.066755832美元，原生25次、262.487秒／0.018605496美元：正确性收益伴随时间高180.0%、费用高258.8%。State末期记录了多布局决定与负例证据，但发生在已修复之后、没有Window移出／回读，不能唯一归因于记忆机制。插件尝试全backend构建时遇到非本包的sqlite CGO错误；tracked改动stash后仍见该错误，说明不能把它混为最终pgbk验证失败。这个stash未包含untracked文件、BASE_EXIT也受head管道影响，不能将其称为完全干净负对照；实际pgbk最终成功有独立回执。原件／自测与官方评分SHA见s28-postgres-timestamp-win-audit-20261029.json。

S30 OpenLibrary，原生官方必需9／11、插件11／11，首分0／1。原生完成类型化更新器和大部分批次重构，但update_keys最终没有return，官方删除／重定向消费者得到None而无法读deletes；插件返回统一聚合SolrUpdateState，覆盖这两条路径。两者自测都修改了测试文件，官方评分恢复完整测试表面后才暴露差距，不能只报“自测全过”。插件210.145秒／0.068665896美元，原生236.497秒／0.072657372美元，分别减少约11.1%／5.5%。插件State记下返回聚合状态，但该写入在业务修复和自测之后，不能倒置因果称State产生了正确实现。没有Window移出或memory_read；另有6次State超长拒绝，最后缩短恢复，收益和工具浪费同时保留。证据s30-plugin-win-audit-20261029.json。

S31 Navidrome，官方3个要求的测试套件原生2过／1失败，插件3过；细项为原生63／64、插件64／64。原生将`-ss 456`插到`-i`与输入文件路径之间，直接违背公开要求的“在输入路径之后”；插件位置正确。插件还将offset加入转码缓存键，但这不是本次决定首分的失败断言。真实解题原生7次模型返回、241.388秒／0.005518680美元，插件10次、262.099秒／0.011336508美元：插件结果更好，时间和费用均更高。插件State保留了生产构建成功、不可修改测试mock等事实；没有Window移出或memory_read。这一胜点是参数顺序和实现质量，不能单凭它证明长程记忆机制起因。

S19 Proton，两侧官方28／28、首分1／1；插件Agent时间少约18.9%、模型估算费用低约11.4%。该例支持同分效率收益。其原补丁含core二进制标记，已经独立验证官方fallback重放后的两份业务文本与干净精确应用逐文件SHA一致；原二进制内容不可恢复的限制仍保留，不能把文本保真扩大为全工作区保真。

S33 Qutebrowser两侧官方均1，插件Agent104.256秒对514.145秒，费用低约14.1%。这只是本次同分观测：原生多次大集合测试遇到尾部中止／XIO，明确有exit1；插件测试范围较小，部分输出仅点号、无完整汇总或原pytest退出码，却仍在State和最终答复称全部通过。故速度差不能解释为相同验证覆盖下的确定效率收益，更不能认定记忆机制起因。官方有效1与自测证据不足分别保留，详见MW-011AB及s26-s27-s33-timing-audit-20261029.json。

T14同键完成倒序，原生和插件整题均0，但受控诊断中插件正确维持最终LSN值，原生3／3旧值覆盖；这是有明确逻辑证据的局部优势。相反，插件将物理写入串行绑到durable前缀，未满足官方并发进度检查。两项结果必须一起报告，不能把局部正确改写成整题通过。

S32官方插件12／13、原生9／13，插件捕获补丁的Meta+Shift+X与expiration UI两项通过，原生对应三项未通过；双方共同缺已有25小时时长在“编辑加密”对话框中的一天剩余提示：原生把计算和文字放到了另一个ExpirationModal，插件部分补丁没有该提示。公开要求明确从duration算天，这不是当前日期或报告格式问题；路径／原件SHA在s32-encryption-sentence-path-audit-20261029.json。插件同时有官方资源结束，不能将补丁分项优势写成正常完整交付。T06插件官方9／13对原生7／13，T04插件27／36对原生26／36，均整题0。这些分项差异可用来定位验证覆盖，不能替代官方整题通过率或称为插件独过。

T13表单迁移两侧官方均0，原生19／28、插件13／28；同一28条中共同通过10、原生独过9、插件独过3、共同失败6。插件独过的003金额／空数字保存、010已开票状态冲突及019明细整批替换说明它有局部优势；其新建父单外键顺序、明细PUT缺校验与前端API接线仍使整题失败。原生68分钟真实浏览器验证后仍有明细ID丢失／覆盖、DOM标识与金额计算问题，不能称“用真浏览器就已完整正确”。插件Agent580.318秒／0.164913228美元，原生4077.886秒／0.277795056美元，时间少85.8%、费用低40.6%，伴随较少通过轨迹，不能当同等质量的效率收益。插件本题25次state_append有20次错误、无Window移出。原生原产物三次复现明细ID覆盖、422状态冲突、DOM标识缺失及金额偏差；插件三次复现入口／保存／PUT问题。原生的选择器缺失不等于资产串号数值错误，整个0.03合计差额尚未唯一隔离。完整对照及公开契约／源码SHA见t13-complete-paired-audit-20261029.json与MW-011AA。
