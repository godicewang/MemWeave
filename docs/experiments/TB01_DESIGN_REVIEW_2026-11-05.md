# TB-01：双跑后构念复审与纠偏

本复审取代“采集通过即可作为本题完整验收”的解释，不覆盖历史评分或原始工件。依据仍为指导文档 v1.3、Library 版本 2，SHA256 `a2abf0ad5c7234dc08068f8040479771424e50b5cdf91509fedf150e8ae62ea1`。本次仅修实验系统，不改产品 Rule、State、Window、默认预算或源题测试。

## 已确认的两项设计缺陷

1. `1.3.3` 的三个“高价值行为”包实际是最终业务正确性、性能合规和重复正确性。它们没有 State 内容真值、依赖动作前的落地时点及后续使用断言。因此这些业务包的零分可复算，但不能冒充 State 记忆行为零分或完整高价值验收。工程原值仍有诊断意义，不能靠采集通过修补构念缺失。
2. 实际 Actor 时限为 5400 秒，准备目录的题面仍声明 28800 秒。两臂均如此也不能称时间口径正确。需要在新准备目录中同步唯一时间声明，并记录原文／有效题面 hash 与差异；原始源题与旧运行不得更改。

## 本轮可独立修复的范围

时间修复从已冻结 `task.toml` 的 Actor timeout 读取秒数，只替换本题唯一的 `You have 28800 seconds to complete this task.` 声明。缺失、重复、源秒数漂移或非法 timeout 均拒绝；其余题面逐字保留。该改动会影响模型可见输入，必须增加 case 版本并从干净起点成对重跑。

付费准入应独立验证设计就绪，不能因为旧 scorer 能产生数字就允许开跑。新的完整验收设计必须声明 State 内容真值、写入截止边界、后续动作 gold、真实采集及正／负／缺证据控制。只有业务测试 ID 的旧合同仍允许离线复算历史报告，但不再获得新的完整验收付费准入。

## State 行为设计的必要边界

应从原题选择少量真实依赖：全 shard 的条件均值校准、非 support 输入位置而非 ID 的行序、生成原始字节的停止条件。每项须将以下必要断言连通：原题已暴露该信息；非 Goal 的实际 F/D 提交内容保留其值、否定及适用范围；提交早于首次依赖动作；后续请求交付或显式回读了对应有效版本；真实下游动作／中间产物通过独立业务 oracle。首次依赖动作需要完整工具前后产物边界，不能以最终代码或 bash 文本猜测。窗口移出与归档失效分开。

自由文本 State 的语义真值目前没有经验证的程序提取器。关键词相交不满足真值判定；强制 JSON 卡片会改变 Actor 输入和被测行为，不能静默加入“自然默认配置”主实验。应先完成不改变 Actor 的有界、可审计语义判定及完整采集，或明确另行讨论派生格式协议。自动注入加最终答对也不等于已经证明采用，更不证明因果收益。需要反事实干预才能作因果归因。

这些缺口不能通过离线给旧 State 补记录、增加事后金标、改名业务指标或把缺项设为 NA 解决。新版本在完成上述语义与真实 CLI 控制前应标 `design_ready=false`、`formal_run_allowed=false`。

追加确认的采集缺口：本题旧 gold 的 `tasks={}` 没有给观察器配置 Python 项目文件，`workspaceSummary()` 因而沿用了 Wasm 的 `/app/interpreter` 默认路径，旧工具边界哈希均不能证明 Python 源文件何时首次改变。新草案必须枚举实际 `evalbench/*.py`，并采工具执行前、执行后、Actor 开始／结束边界。State 同边界只记已绑定 task、journal 版本／哈希及错误，正文继续由最终原件重放，不能新增常驻全量快照或把事件 `time` 当成可信落地时刻。此采集组件可先做免费控制，但不等于语义 oracle 已完成。工具边界哈希只能证明观测时点保全，不能证明同一工具内部从未短暂写入又恢复。

## 时间与费用边界

原授权为本题新增 USD 5、3 小时，按最早可靠执行时间 02:25:05 UTC 计；本轮主动采用更早的 05:20:00 UTC 截止。重跑不重置授权时钟、旧账本或未知预留。04:00 UTC 后剩余约 80 分钟，已不足以完成设计修正、免费真实 CLI 验收、完整 90 分钟 Actor 双跑、最多 15 分钟 verifier 和收尾。因此本轮不再发新的付费模型请求；只能完成免费修复、复审和封存。需要延长时间时由父任务向用户说明准确计划，不自行延长。

一轮后续完整尝试的建议时间安排是：60 分钟完成 State oracle／采集与实际 CLI 免费验收，10 分钟准备和小额 canary，90 分钟对称 Actor 上限，15 分钟并行 verifier，10 分钟报告清理，共 185 分钟。该安排是工程估计而非完成保证；失败或未知费用仍受总 USD 5 限额约束。不得以压缩 Actor 时间换“已完成”标记。
