## P0计算

- 逻辑操作：仅由明确evaluation_operation_id关联尝试；重复工具/参数不构成重试。首次失败、预先标可恢复、已到截止且外部状态有证据才给恢复率。回执成功不证明外部状态。重试负载为明确逻辑操作中首尝试之外的尝试/全部映射尝试；未映射覆盖和成本/耗时缺值单列。
- 最新State：严格指标要求同一评估序列中的真实commit和request-prepare边界及完整性声明。State事件time生成早于提交，不能替代commit。现有轨迹缺这类边界则unknown。另算请求可见写入回执确认版本的因果下界：用Session回执、真实journal op_id和实际请求tool_call_id关联，交付版本不得低于其已包含的回执版本；不是全局最新证明。
- Window：声明完整事件投影的gold与实际投影分别提供event_id、scope、kind、call_id、hash；检查事件完整、调用结果配对、顺序、scope与投影hash。缺预裁剪/预期投影，不能仅从Session猜实际保真。现有payload摘要缺assistant call IDs及预期投影，严格指标unknown。
- 引用：每次已知读取机会比较预登记ref/scope/版本/授权投影hash和实际解析结果，错误算失败，缺结果unknown。零读取机会N/A；不声称模型本来不需要读取。截断按预登记允许投影检查，不与原文全量hash混用。
