# MAB最终回答证据修复

仅修现有评估侧的日志恢复／缺证据口径，不改题面、模型、工具或评分金标。旧版缺少`steps/query/agent/pi.txt`会默认空字符串，甚至把缺query目录直接当失败，无法区分日志丢失与实际未执行。

新版先读取完整合法JSONL的原Pi输出；不可用时，仅从该query阶段已有的`execution-invocations`清单及字节数／SHA256匹配的原始stdout恢复。多调用按既有单调起始记录排序；无法确定先后时保持缺证据。若冻结的预期阶段清单与Harbor原始终态明确证明query在已知中止后未开始，可判任务未完成0；只缺目录、缺清单、损坏日志或未知终态不能推成0。缺失最终回答而文件答案正确时，该联合检查点仍unknown，并阻止采集验收。

离线修复对两臂使用同版，输出新目录，旧原件不改。正／负／损坏／缺字段测试仅验证程序，不当真实模型成绩。此修复不等于MAB完整业务gold和所有35题已准入。

修复还将文件值判定与终答捕获独立计算：终答缺失但文件正确时，回答断言缺证据、文件断言通过，联合点unknown；不能因终答缺失把已知正确文件强制判错。原始stdout与派生Pi日志冲突时保持缺证据，不挑有利答案。

最终全量656项实验测试、276项仓库检查以及Ruff／diff检查通过。5份既有真实CLI stdout实际经过独立哈希／长度／阶段／终态核对，24份更早MAB控制的合法Pi日志仍可识别；早期未保存独立stdout的控制不声称能恢复该原件。新增捕获记录单调时钟顺序；旧捕获仅在有明确wall-clock顺序时使用并披露来源。无付费调用，正式35题仍0。
