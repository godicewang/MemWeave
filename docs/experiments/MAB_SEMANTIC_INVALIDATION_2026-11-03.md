# MAB纠错：窗口隐藏不等于语义失效

本次仅修评估侧，不改State schema、归档／窗口工具、模型提示或已有轨迹。旧v17—v25结果不覆写，新版本重算明确标注评分器。

既有active_text将slide_window移出的Fact／Decision从可见集删除，也用于“无冲突当前记录”的检查。这只能证明旧项未展示，不能证明其已归档。实际契约中窗口驱逐与modify_fact.archive不同，旧项可按已知ID回读；用户又明确要求过时结论不能继续有效。因此需要两个投影：可见且未归档条目，以及所有未归档条目。

有限MAB当前事实／书籍事件检查点，所需正确卡仍须在依赖动作前可见；不兼容、仍适用的旧卡则在整个未归档集合检查，不能靠窗口隐藏刷过纠错。真正归档后保留历史允许通过。C4三个真实驱逐检查继续核对实际请求交付的可见记忆，不把语义journal投影伪装成模型已看见。无法获得完整journal时旧项有效性为unknown，不能从只看到正确卡推出无冲突。

该范围仅有限JSON事实／事件语法和预冻结的不兼容集合，不是通用自由文本矛盾识别。书籍卡只匹配明确同事件／限定的反例，不把同人物的其他事件认定污染。所有改动先以窗口隐藏、真正归档、当前卡自身不可见、缺语义投影、错误实体／范围等正负missing用例验证，再重放已有完整CLI原件；免费控制不变成模型成绩。

新增10项边界用例及全量813项离线回归通过。八个MAB原始软件轨迹通过既有report入口在独立`mab-semantic-v26`目录重算，原有正确归档正例的已评分组件值均未变；完整适用矩阵仍有未解决项，整题采集验收仍false，不能称正式模型评测完成。记录语法／Actor输入不变，有限卡片评分ID升级为invalidation v2，主评分器v26；先前源轨迹、合同与报告哈希保留。
