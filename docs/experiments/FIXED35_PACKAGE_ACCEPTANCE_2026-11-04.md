# fixed35整包能力与长例资格验收

此补丁兑现续轮设计审计中的整包门禁，不改变逐题适用性、actor输入、产品契约或正在运行的冻结评分器。历史v5输出保留；现有`fixed35 pack-report`新增v6输出，仍须使用新目录。

`collection_accepted`只回答冻结case×metric采集是否完整。新增`capability_coverage`对Q1–Q8、S1–S4、C1–C8、T1–T4共24组单独统计正式插件证据：完整、已评分的0分同样算有观测，不代表通过；设计NA、零机会、未运行、缺证据、原生和fixture均不能填覆盖。别名及子断言不增加组数；State交付只能覆盖Q8，不能冒充Q4引用／Window保真。

整包manifest可携带`long_qualification: {path, sha256}`。验证器不信任手填合格数，而是对固定五题逐一重读冻结formal admission、原始结果、report、实际账本及去重已完成actor请求ID，复算每个资格。原验证器成功且同一次正式参考臂至少1000个真实完成调用才合格。没有证明时为unknown而非0次；空正式尝试且明确五题均未合格时可确认0/5。历史外部证据、工具、辅助请求、mock及多次尝试之和均不补足资格。

`package_accepted`仅在采集完整、24组均有真实观测、五题资格全部核验通过时为true。它不阻断其他已完整准入题的独立运行，也不把所有能力强加到每题。每题得分、共同口径分母、原始值及权重保持原定义；整包验收不通过时不能把有效子集高分称为完整交付。

验证包括已知0、缺失／零机会、原生排除、别名去重、非法分数、长例标志伪造、实际原件重放及既有CLI整包接线。完整实验回归使用本机替身HTTP监听，不发付费请求；普通沙箱运行的6项本地监听检查因EPERM受阻，随后通过工具批准的离线回归入口重跑。具体最终命令与日志记录在本轮交付清单中。
