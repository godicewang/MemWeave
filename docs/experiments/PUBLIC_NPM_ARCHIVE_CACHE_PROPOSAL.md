## 第一部分：目的与范围

只复制已知官方公开URL对应的这一份内容；不复制个人npmrc、认证、其他缓存、配置、已安装依赖树、Session或记忆。官方镜像／任务／依赖版本、网络及单题额度不变，正式模型Trial仍只读密封软件对象。模型重试仍0；累计0.093063336美元、原20美元及2026-10-30 18:48:39 CST截止不变。

接入会改变软件准备代码和缓存记录，需按AGENTS第2节及缓存设计§1–2先确认；另一方案是停止本轮、整理现有结果。不是继续用相同网络安装反复碰运气。

## 第二部分：最小接线

仅为锁定onnxruntime-node@1.30.0提供公开归档描述符和URL／SSRI／SHA收据。首次从已验证的单份公开本机缓存内容导入，缺失或损坏明确报错；不自动读取整个用户缓存。来源为官方registry.npmjs.org URL，归档校验包名／版本与SHA-512，每次使用复核内容。

prepare_only的build_addon上传归档，用固定Node自带npm的offline cache add灌入容器独立缓存，再运行原安装命令；缺失的其他依赖仍按既定无凭据准备网络获取。禁止安装脚本与原参数保持一致，不跨镜像复用安装产物。先在network=none的新官方镜像中验证npm可按原URL＋integrity从种入缓存恢复字节一致的tarball，再做完整真实Harbor无模型预检。

新旧适配器只允许这一份已批准准备下载变化及此前Node探针变化，用明确SHA对审查后保留原模型结果链。准备配方新键仍按原规则冻结，旧对象不改名、不伪造身份；完成／中断模型尝试和首次成绩不重跑，原费用／截止完整继承。
