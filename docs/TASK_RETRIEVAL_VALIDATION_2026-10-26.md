## 本机检索与资源控制实验

Node 24.22.0，macOS arm64，固定 E5 revision `761b726dd34fb83930e26aab4e9ac3899aa1fa78`，384 维、512 模型 token；query/passage 前缀、mean pooling、L2。模型/许可证来源见包内 resources/embedding/README.md。原模型卡声明 MIT，所有5个下载文件按固定大小/SHA-256校验。模型资源合计135,392,183 bytes，原生运行库安装空间另计；权重不随归档发布。

直接 ONNX 与 Transformers.js 参考实现的三个样本向量最大绝对差 `2.56e-8`，不是两套模型质量对比。省去浏览器/图像推理依赖，只保留 CPU 本机嵌入。

12 个固定自造查询，覆盖同义表达、中英跨语、相近工程主题；8个Task目标，真实本地向量、固定词项/融合设置。混合 Top-1 为10/12、Top-3为12/12；相同词项通道 Top-1 为3/12。两项混合首位误召回仍保留在记录中，正确Task排第3；不调参掩盖，Top-k由Agent判断。样本很小，不能当公开基准或一般质量保证。

| 控制实验 | 实际结果 | 边界 |
|---|---|---|
| 已有模型文件冷加载＋8个短Goal向量 | 432ms | 包含本机校验/工作线程启动，不含首次网络下载/主Pi启动 |
| 12个热查询及融合 | 每个约2.3–7.6ms | 仅8个目标；不是完整Task文件扫描时间 |
| 1,000 / 10,000条发现元数据排序 | 12.5 / 123.2ms | 复用真实向量的合成规模，排除磁盘读取/重嵌入，不冒充完整请求 |
| 过长查询 | 明确拒绝超过512模型token | 不默默截断查询；文档截断有 index_truncated 标记 |
| 模型加载/释放10次 | 活跃RSS约678–768MB；释放后约658–744MB，后段趋稳 | 包含进程/分词器/原生分配；释放不保证RSS立即回落，不据此证明长期无泄漏 |

行缓存有32MiB估算驻留限额，工作线程JS堆限制256MiB；两者都不是全进程RSS上限。推理输入/输出Tensor在finally释放，空闲60秒明确释放原生Session再退出，异常5秒后强制结束；替代线程等待旧线程退出，退出后不保留查询结果。文件哈希采用流式读取，避免每次校验在主线程分配完整135MB字符串/字节副本。

### 仍失败：验证受阻后未保存失败边界

真实组件任务要求修复超时并实际验证，验证受阻则说明原因和未完成部分、不要反复重试。模型调用inspect_component、task_create、set_component_timeout、verify_component；工具返回passed=false及fixture transport blocked。最后答复明确“配置已修复、验证被阻塞”，但没有调用state_append，State没有保存受阻边界。不是OCR格式/测试语义问题，也不是State写入失败；未发生写入调用。保留失败断言，不重复采样至通过，不自动生成认知或追加提示叠甲。绑定改进不保证每次保存重要认知。
