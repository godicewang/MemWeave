## 实现与范围

默认值唯一维护点为 src/config/defaults.json；可选 ~/.pi/memory/config.json 仅保存用户覆盖。已有六字段文件兼容，State 字段可以省略，缺少文件不生成、不报缺失错误；损坏文件、未知字段、非法值仍拒绝。嵌套策略逐项合并，原六字段分支覆盖优先，scope 格式及 Agent N/B 工具不变。

已接通预算百分比、自动窗口、State 预警线、回读期限/默认字符数、来源缓存和元数据超时。所有模块使用同一请求快照；真实成本扣除、输出限额、State 准入及尾部提示一致。N/B 规划仍使用 Window 比例向下取整后的值，避免总分区舍入余数改变旧的自动窗口边界。

四个新 Rule 占位符与固定协议两份副本同步。默认策略兼容六变量模板；非默认策略缺对应占位符时主动取消，不自动改写用户模板。旧版本升级测试使用旧包自己的模板，验证升级后该用户文件仍不变；不把新十变量模板强塞给旧程序后误报兼容失败。
